Birgitta Böckeler argues that linters and static analysis tools have become more valuable when working with AI coding agents, because the agents can use tool output to self-correct mistakes. The article walks through practical setups using ESLint and similar tools to catch common AI shortcomings like excessive function length and complexity. She notes that while these sensors help with structural issues, detecting semantic quality problems remains out of reach.
