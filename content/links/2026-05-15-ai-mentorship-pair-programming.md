AI coding agents have changed how mentorship pair programming works - code generation is fast enough that visible friction points like syntax and boilerplate have mostly disappeared. The comprehension gaps that mentorship used to surface haven't gone away, they've just shifted earlier in the development process. Senior developers now spend more time probing whether juniors actually understand what the AI produced than helping them write it.
